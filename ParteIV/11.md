## 11. Portabilidad, interoperabilidad y migración

Estos conceptos están relacionados, pero no son equivalentes.

### Portabilidad

La portabilidad responde:

> ¿Puede la aplicación utilizar otro proveedor sin modificar su lógica de negocio?

Ejemplo:

```text
La misma aplicación funciona con S3, MinIO y Ceph RGW.
```

### Interoperabilidad

La interoperabilidad responde:

> ¿Pueden dos sistemas diferentes intercambiar información mediante contratos compatibles?

Ejemplo:

```text
Un objeto almacenado en MinIO puede trasladarse y utilizarse en Ceph RGW.
```

### Migración

La migración responde:

> ¿Cómo trasladamos los datos de un proveedor a otro de forma controlada?

Ejemplos:

```text
Amazon S3 -> MinIO
MinIO -> Ceph RGW
Ceph RGW -> Amazon S3
```

### Responsabilidades

La aplicación es responsable de:

* Utilizar un contrato portable.
* Mantener keys neutrales.
* Validar resultados.
* Evitar dependencias innecesarias.

La plataforma es responsable de:

* Disponibilidad.
* Durabilidad.
* Seguridad.
* Credenciales.
* Red.
* Backups.
* Monitoreo.

El proceso de migración es responsable de:

* Copiar datos.
* Preservar metadata.
* Validar integridad.
* Registrar errores.
* Reintentar.
* Coordinar el corte.
* Permitir rollback.
