# Laboratorio 2. Migrador JavaFX

## Objetivo:

Demostrar que los objetos pueden trasladarse entre proveedores compatibles con S3, conservando contenido, metadata e integridad.

## Flujos:

```
Amazon S3 -> MinIO
MinIO -> Ceph RGW
Ceph RGW -> Amazon S3
```

## Concepto principal:

Interoperabilidad y movilidad de los datos.
