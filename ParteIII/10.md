## 10. Cambio de proveedor

La aplicación se ejecutará contra:

* Amazon S3.
* MinIO.
* Ceph RGW.

### Comparación de configuración

Ejemplo para Amazon S3:

```yaml
storage:
  provider: aws
  region: us-east-1
  bucket: product-images
  path-style-access: false
```

Ejemplo para MinIO:

```yaml
storage:
  provider: minio
  endpoint: http://localhost:9000
  region: us-east-1
  bucket: product-images
  path-style-access: true
```

Ejemplo para Ceph RGW:

```yaml
storage:
  provider: ceph
  endpoint: http://localhost:8080
  region: us-east-1
  bucket: product-images
  path-style-access: true
```

### Evidencia de que el código de negocio no cambia

La demostración deberá mostrar:

1. La misma versión de la aplicación.
2. El mismo código.
3. Las mismas pruebas.
4. Diferentes configuraciones.
5. Diferentes backends.
6. El mismo comportamiento funcional.

La portabilidad no debe afirmarse solamente.

Debe verificarse mediante ejecución y pruebas.
