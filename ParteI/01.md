## 1. Por qué importa el almacenamiento

El almacenamiento es una de las capacidades fundamentales de cualquier sistema de software.

Mientras que el procesamiento ejecuta operaciones sobre los datos, el almacenamiento permite conservarlos más allá del ciclo de vida de un proceso, una aplicación, un contenedor o una máquina.

### Persistencia frente a procesamiento

El procesamiento transforma información:

* Ejecuta reglas de negocio.
* Calcula resultados.
* Valida solicitudes.
* Genera respuestas.
* Coordina flujos de trabajo.

El almacenamiento conserva información:

* Registros de clientes.
* Productos.
* Imágenes.
* Documentos.
* Logs.
* Métricas.
* Backups.
* Configuraciones.

Una aplicación puede reiniciarse o trasladarse entre nodos, pero sus datos deben permanecer disponibles.

### Datos estructurados y no estructurados

Los datos estructurados siguen un modelo claramente definido.

Ejemplos:

* Tablas relacionales.
* Registros de clientes.
* Transacciones.
* Inventarios.
* Órdenes de compra.

Los datos no estructurados no siguen necesariamente un esquema tabular.

Ejemplos:

* Imágenes.
* Videos.
* Archivos PDF.
* Audios.
* Backups.
* Logs.
* Modelos de inteligencia artificial.

La naturaleza de los datos influye directamente en el modelo de almacenamiento más adecuado.

### Durabilidad, disponibilidad y rendimiento

Al elegir una solución de almacenamiento deben evaluarse al menos tres propiedades.

#### Durabilidad

Representa la capacidad de conservar los datos correctamente durante largos periodos.

Un sistema durable debe proteger la información frente a:

* Fallos de discos.
* Reinicios.
* Pérdida de nodos.
* Corrupción de datos.
* Errores operativos.

#### Disponibilidad

Representa la capacidad de acceder a los datos cuando son requeridos.

Una plataforma altamente disponible puede continuar operando aun cuando algunos de sus componentes fallen.

#### Rendimiento

Representa la velocidad con la que el sistema puede leer o escribir información.

El rendimiento puede medirse mediante:

* Latencia.
* Operaciones por segundo.
* Throughput.
* Tiempo de respuesta.
* Ancho de banda.

No todas las cargas requieren el mismo equilibrio entre durabilidad, disponibilidad y rendimiento.

### Almacenamiento administrado frente a self-hosted

Un servicio administrado delega al proveedor tareas como:

* Instalación.
* Parches.
* Actualizaciones.
* Replicación.
* Monitoreo.
* Recuperación.
* Escalamiento.

Ejemplos:

* Amazon S3.
* Amazon EBS.
* Amazon EFS.
* Azure Blob Storage.
* Google Cloud Storage.

Una solución self-hosted debe ser instalada y operada por la organización.

Ejemplos:

* MinIO.
* Ceph.
* RustFS.
* SeaweedFS.

El almacenamiento administrado reduce la carga operativa, mientras que una solución self-hosted ofrece mayor control, portabilidad y flexibilidad de despliegue.
