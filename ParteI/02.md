## 2. Modelos de almacenamiento

Los principales modelos de almacenamiento utilizados en plataformas cloud-native son:

* Object Storage.
* Block Storage.
* File Storage.
* Almacenamiento efímero.
* Archive Storage.

### 2.1 Object Storage

Object Storage organiza la información como objetos independientes.

Cada objeto contiene:

* Datos.
* Una clave o identificador.
* Metadata.
* Información asociada al contenido.

Los objetos suelen organizarse dentro de buckets.

Casos de uso:

* Imágenes.
* Videos.
* Documentos.
* Logs.
* Backups.
* Data lakes.
* Artefactos de software.

Ejemplos:

* Amazon S3.
* MinIO.
* Ceph RGW.
* Azure Blob Storage.
* Google Cloud Storage.

### 2.2 Block Storage

Block Storage presenta el almacenamiento como un dispositivo de bloques similar a un disco.

El sistema operativo puede:

* Crear particiones.
* Formatear el dispositivo.
* Crear un sistema de archivos.
* Montarlo.
* Utilizarlo como disco persistente.

Casos de uso:

* Bases de datos.
* Sistemas operativos.
* Máquinas virtuales.
* Volúmenes persistentes de Kubernetes.
* Aplicaciones con operaciones frecuentes de lectura y escritura.

Ejemplos:

* Amazon EBS.
* Azure Managed Disks.
* Google Persistent Disk.
* Ceph RBD.

### 2.3 File Storage

File Storage presenta una estructura jerárquica de directorios y archivos.

Los clientes interactúan mediante operaciones tradicionales:

* Crear archivos.
* Abrir archivos.
* Leer.
* Escribir.
* Renombrar.
* Mover.
* Eliminar.

Casos de uso:

* Directorios compartidos.
* Contenido web compartido.
* Airflow DAGs.
* WordPress.
* Home directories.
* Aplicaciones que requieren volúmenes ReadWriteMany.

Ejemplos:

* Amazon EFS.
* Azure Files.
* Google Filestore.
* CephFS.

### 2.4 Almacenamiento efímero

El almacenamiento efímero existe únicamente durante la vida de un proceso, contenedor, pod o máquina.

Cuando el recurso desaparece, los datos también pueden desaparecer.

Casos de uso:

* Archivos temporales.
* Cachés locales.
* Espacios de trabajo.
* Resultados intermedios.
* Datos que pueden reconstruirse.

En Kubernetes, el almacenamiento local del contenedor y ciertos volúmenes como `emptyDir` son ejemplos de almacenamiento efímero.

### 2.5 Archive Storage

Archive Storage es una especialización orientada a conservar datos durante largos periodos con costos reducidos.

A cambio, normalmente ofrece:

* Mayor latencia de recuperación.
* Menor frecuencia de acceso.
* Posibles costos de restauración.
* Restricciones de permanencia mínima.

Casos de uso:

* Respaldos históricos.
* Evidencia regulatoria.
* Registros de auditoría.
* Documentos legales.
* Datos de acceso poco frecuente.

Ejemplos:

* Amazon S3 Glacier.
* Azure Archive Storage.
* Google Cloud Archive Storage.
