## 4. Cómo elegir

La elección del modelo de almacenamiento debe partir del patrón de uso y no del nombre del producto.

### Patrón de acceso

Debe determinarse cómo se utilizarán los datos:

* Lecturas frecuentes.
* Escrituras frecuentes.
* Acceso secuencial.
* Acceso aleatorio.
* Lectura completa.
* Modificaciones parciales.
* Compartición entre varios consumidores.

### Latencia

Algunas aplicaciones necesitan respuestas en milisegundos.

Otras pueden aceptar tiempos de recuperación mayores.

Ejemplos:

* Una base de datos necesita baja latencia.
* Una imagen web requiere acceso rápido.
* Un backup histórico puede tolerar minutos u horas para su restauración.

### Jerarquía

File Storage presenta una jerarquía real de directorios.

Object Storage normalmente simula carpetas mediante prefijos dentro de las claves de los objetos.

Por ejemplo:

```text
products/123/images/main.webp
```

Aunque visualmente parezca una estructura de carpetas, para Object Storage sigue siendo una clave completa.

### Escrituras parciales

Block Storage y File Storage permiten modificar partes específicas de un archivo o dispositivo.

En Object Storage, un objeto suele reemplazarse completamente cuando cambia.

### Concurrencia

Debe analizarse cuántos consumidores accederán simultáneamente al almacenamiento.

Preguntas relevantes:

* ¿Un solo nodo utilizará el volumen?
* ¿Múltiples aplicaciones compartirán archivos?
* ¿Los objetos serán consultados por miles de clientes?
* ¿Habrá escrituras concurrentes sobre el mismo recurso?

### Escala

Object Storage está diseñado para manejar grandes cantidades de objetos y crecer horizontalmente.

Block Storage suele escalar mediante volúmenes.

File Storage debe administrar tanto la capacidad como la estructura jerárquica compartida.

### Costo operativo

El costo no incluye únicamente infraestructura.

También debe considerar:

* Administración.
* Actualizaciones.
* Monitoreo.
* Backups.
* Recuperación.
* Personal especializado.
* Ancho de banda.
* Replicación.
* Costos de egreso.
* Complejidad operacional.
