## 18. Plataforma unificada

Ceph puede proporcionar Object, Block y File Storage desde una misma plataforma distribuida.

```text
                     Ceph

        +--------------+--------------+
        |              |              |
       RGW            RBD          CephFS
        |              |              |
     Object          Block           File
        |              |              |
     Imágenes      PostgreSQL     Compartidos
     Backups       Volúmenes      DAGs
     Logs          Máquinas       Uploads
```

### Ventajas

* Plataforma unificada.
* Infraestructura compartida.
* Escalamiento horizontal.
* Replicación.
* Tolerancia a fallos.
* Integración con Kubernetes.
* Compatibilidad S3 mediante RGW.
* Block Storage mediante RBD.
* File Storage mediante CephFS.

### Costos

El uso de Ceph implica costos de:

* Hardware.
* Discos.
* CPU.
* Memoria.
* Red.
* Replicación.
* Monitoreo.
* Backups.
* Operación.
* Capacitación.

### CPU, memoria y red

Ceph realiza tareas internas como:

* Replicación.
* Recuperación.
* Scrubbing.
* Rebalanceo.
* Verificación.
* Distribución de datos.

Estas operaciones consumen recursos incluso cuando las aplicaciones no realizan solicitudes directas.

### Complejidad operativa

Operar Ceph requiere comprender:

* MON.
* MGR.
* OSD.
* RGW.
* MDS.
* Pools.
* Placement Groups.
* CRUSH maps.
* Replicación.
* Erasure coding.
* Recovery.
* Scrubbing.
* Health states.

### Cuándo sí usar Ceph

Ceph puede ser apropiado cuando:

* Se requiere Object, Block y File Storage.
* Existe infraestructura propia.
* Se necesita evitar dependencia de un proveedor cloud.
* La escala justifica una plataforma distribuida.
* Existe un equipo capaz de operarla.
* Kubernetes necesita almacenamiento persistente avanzado.
* Se requieren múltiples servicios sobre una base común.

### Cuándo sería excesivo

Ceph puede ser excesivo cuando:

* Solo se necesita almacenar unas pocas imágenes.
* Un servicio administrado cubre los requisitos.
* No existe personal especializado.
* La infraestructura es pequeña.
* La complejidad operativa supera el beneficio.
* MinIO u otra solución simple cubre el caso de Object Storage.
* Un volumen administrado es suficiente.
