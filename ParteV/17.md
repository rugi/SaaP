## 17. Caso File Storage

### Directorio compartido

CephFS permite presentar un sistema de archivos compartido.

Ejemplo:

```text
/shared
├── reports
├── uploads
├── dags
└── exports
```

### Múltiples consumidores

Varios servidores o pods pueden montar el mismo sistema de archivos.

Casos de uso:

* Airflow DAGs.
* Archivos compartidos.
* WordPress uploads.
* Contenido generado por múltiples réplicas.
* Directorios de trabajo comunes.

### Lectura y escritura simultánea

File Storage permite que múltiples consumidores interactúen con una jerarquía común.

Esto requiere coordinación de:

* Permisos.
* Locks.
* Metadata.
* Consistencia.
* Acceso concurrente.

### Concepto de CephFS

CephFS utiliza componentes especializados para administrar metadata del sistema de archivos.

La aplicación utiliza una interfaz de archivos tradicional, mientras Ceph distribuye los datos internamente.
