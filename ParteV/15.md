## 15. Ceph no es solamente Object Storage

Ceph ofrece tres modelos principales de almacenamiento.

```text
RGW    -> Object Storage
RBD    -> Block Storage
CephFS -> File Storage
```

### RGW

RADOS Gateway proporciona interfaces de Object Storage.

Puede exponer:

* API compatible con S3.
* API compatible con Swift.

### RBD

RADOS Block Device proporciona dispositivos de bloques distribuidos.

Puede utilizarse para:

* Máquinas virtuales.
* Bases de datos.
* Kubernetes Persistent Volumes.
* Sistemas de archivos.

### CephFS

CephFS proporciona un sistema de archivos distribuido.

Puede ser montado simultáneamente por múltiples clientes.
