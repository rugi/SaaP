## 7. Compatibilidad no significa igualdad

Dos productos compatibles con S3 pueden implementar las operaciones principales de forma similar, pero no necesariamente ofrecen las mismas capacidades.

### Núcleo portable

Las operaciones más portables suelen ser:

* Crear buckets.
* Subir objetos.
* Descargar objetos.
* Eliminar objetos.
* Listar objetos.
* Consultar metadata.
* Multipart upload.
* Generar URLs firmadas.

### Funcionalidades específicas

Las diferencias suelen aparecer en:

* IAM.
* Cifrado.
* KMS.
* Object Lock.
* Versionado.
* Replicación.
* Lifecycle.
* Eventos.
* Notificaciones.
* ACLs.
* Tags.
* Checksums.
* Semántica de ETags.

### Lock-in de API frente a lock-in operacional

El lock-in de API ocurre cuando la aplicación depende directamente de funcionalidades exclusivas de un proveedor.

El lock-in operacional ocurre cuando la organización depende de:

* Herramientas específicas.
* Procesos de administración.
* Modelos de seguridad.
* Servicios integrados.
* Experiencia especializada.
* Automatizaciones propias del proveedor.

Una aplicación puede evitar el lock-in de código y, aun así, mantener dependencias operacionales importantes.
