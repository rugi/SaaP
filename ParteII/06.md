## 6. Alternativas compatibles

El laboratorio inicial utilizará tres backends principales:

* Amazon S3.
* MinIO.
* Ceph RGW.

### Amazon S3

Amazon S3 es un servicio administrado de Object Storage.

Ventajas:

* Alta durabilidad.
* Escalamiento administrado.
* Integración con AWS.
* IAM.
* Versionado.
* Lifecycle.
* Replicación.
* Eventos.
* Amplio ecosistema.

Consideraciones:

* Dependencia del proveedor.
* Costos de transferencia.
* Costos de egreso.
* Servicios avanzados específicos de AWS.

### MinIO

MinIO es una plataforma de Object Storage compatible con la API S3.

Ventajas:

* Fácil de ejecutar localmente.
* Buena experiencia de desarrollo.
* Compatible con herramientas S3.
* Adecuado para laboratorios.
* Despliegue en infraestructura propia.

Consideraciones:

* Operación self-hosted.
* Administración de discos.
* Backups.
* Alta disponibilidad.
* Actualizaciones.
* Cambios en el modelo de distribución del proyecto.

### Ceph RGW

Ceph Object Gateway, también conocido como RGW, proporciona una interfaz compatible con S3.

Ventajas:

* Forma parte de una plataforma de almacenamiento completa.
* Permite Object Storage.
* Integración con Ceph.
* Escalamiento distribuido.
* Despliegue en infraestructura propia.

Consideraciones:

* Mayor complejidad operativa.
* Más componentes.
* Consumo de CPU, memoria y red.
* Curva de aprendizaje.
* Requiere diseño cuidadoso del clúster.

### Cuarta alternativa opcional

No se incorporará una cuarta plataforma en la primera versión del laboratorio.

La historia inicial debe consolidarse con:

```text
Amazon S3
MinIO
Ceph RGW
```

Posteriormente podría evaluarse una alternativa adicional, por ejemplo:

* RustFS.
* SeaweedFS.
* Apache Ozone.
* Cloudflare R2.
* Wasabi.

La cuarta implementación debe incorporarse únicamente cuando aporte una comparación relevante y no complique innecesariamente el mensaje principal.
