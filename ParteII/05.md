## 5. Amazon S3 como estándar de facto

Amazon S3 popularizó un modelo de API que posteriormente fue adoptado por numerosos proveedores y proyectos de almacenamiento.

Aunque la API S3 no es un estándar formal universal, funciona como un estándar de facto dentro del ecosistema de Object Storage.

### API S3

La API permite realizar operaciones como:

* Crear buckets.
* Subir objetos.
* Descargar objetos.
* Listar objetos.
* Eliminar objetos.
* Consultar metadata.
* Realizar multipart uploads.
* Generar URLs firmadas.
* Administrar versionado.

Operaciones comunes:

```text
PutObject
GetObject
DeleteObject
ListObjectsV2
HeadObject
CreateMultipartUpload
UploadPart
CompleteMultipartUpload
```

### SDK

AWS ofrece SDKs para diferentes lenguajes.

Ejemplos:

* AWS SDK for Java.
* AWS SDK for Python.
* AWS SDK for JavaScript.
* AWS SDK for Go.
* AWS SDK for .NET.

Una aplicación Java puede utilizar el mismo SDK para conectarse a Amazon S3 y a otros proveedores compatibles.

### Buckets

Amazon S3 utiliza buckets como unidad principal de organización.

Cada bucket puede tener:

* Políticas.
* Versionado.
* Lifecycle.
* Cifrado.
* Eventos.
* Replicación.
* Control de acceso.

### URLs firmadas

Una URL firmada permite acceder temporalmente a un objeto sin hacer público el bucket.

Ejemplo de flujo:

```text
Cliente
   |
   | Solicita acceso
   v
Aplicación
   |
   | Genera URL firmada
   v
Object Storage
```

Las URLs firmadas pueden utilizarse para:

* Descargar un archivo.
* Visualizar una imagen.
* Subir directamente un objeto.
* Compartir contenido de forma temporal.

### Versionado

El versionado conserva diferentes versiones de un mismo objeto.

Puede proteger frente a:

* Eliminaciones accidentales.
* Sobrescrituras.
* Cambios no deseados.
* Errores de aplicaciones.

El versionado también aumenta el consumo de almacenamiento y requiere políticas de limpieza.

### Lifecycle

Las reglas de lifecycle permiten automatizar acciones sobre los objetos.

Ejemplos:

* Mover objetos a una clase de almacenamiento más económica.
* Eliminar objetos antiguos.
* Limpiar cargas multipart incompletas.
* Eliminar versiones anteriores.
* Archivar backups.

### IAM

Amazon S3 utiliza IAM para controlar el acceso.

Las políticas pueden limitar:

* Buckets.
* Prefijos.
* Operaciones.
* Usuarios.
* Roles.
* Aplicaciones.
* Condiciones de acceso.

Ejemplo conceptual:

```text
La aplicación puede:

- Subir objetos en product-images.
- Leer objetos en product-images.
- Eliminar únicamente objetos bajo su tenant.
- No modificar las políticas del bucket.
```
